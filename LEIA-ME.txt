 O QUE ESTE AGENTE FAZ
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

Para cada produto no seu arquivo produtos.json, ele:

  1. Gera um roteiro persuasivo com IA (Claude)
  2. Narra o roteiro com voz humana realista (ElevenLabs)
  3. Monta um vídeo vertical (1080x1920) no formato TikTok
  4. Salva tudo organizado numa pasta:
     └── output/
         └── prod_001/
             ├── video.mp4              ← sobe no TikTok
             ├── legenda.txt            ← cola na descrição
             ├── link.txt               ← link afiliado
             └── INSTRUCOES_POSTAGEM.txt ← passo a passo

 CONFIGURAÇÃO — PASSO A PASSO (faça UMA VEZ)
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

PASSO 1 — Instalar dependências
  Abra o terminal na pasta do projeto e rode:
  
    pip install -r requirements.txt

  Se der erro no moviepy, tente:
    pip install moviepy==1.0.3 --no-deps
    pip install decorator imageio imageio-ffmpeg tqdm

─────────────────────────────────────────────────────────────────

PASSO 2 — Criar o arquivo .env
  Copie o arquivo .env.exemplo e renomeie para .env:
  
  Windows:  copie .env.exemplo .env
  Linux/Mac: cp .env.exemplo .env
  
  Abra o .env com qualquer editor de texto (Bloco de Notas funciona).

─────────────────────────────────────────────────────────────────

PASSO 3 — Preencher as chaves no .env

  [OBRIGATÓRIO] ANTHROPIC_API_KEY
  • Acesse: https://console.anthropic.com
  • Clique em "API Keys" → "Create Key"
  • Cole no .env: ANTHROPIC_API_KEY=sk-ant-...

  [OBRIGATÓRIO] ELEVENLABS_API_KEY e ELEVENLABS_VOICE_ID
  • Acesse: https://elevenlabs.io → crie conta gratuita
  • Vá em Profile → API Key → copie
  • Vá em Voices → Voice Library → filtre por "Portuguese"
  • Escolha uma voz → clique → copie o "Voice ID"
  • Cole no .env:
      ELEVENLABS_API_KEY=...
      ELEVENLABS_VOICE_ID=...
  
  [OBRIGATÓRIO] TELEGRAM_TOKEN e TELEGRAM_CHAT_ID
• Acesse o Telegram, busque por @BotFather e mande a mensagem /newbot
• Siga os passos na tela para criar o bot e copie o token gerado (ex: 123456:ABC-DEF...)
• Envie um "Olá" para o seu novo bot recém-criado.
• Para descobrir seu Chat ID, acesse no navegador: https://api.telegram.org/bot<SEU_TOKEN_AQUI>/getUpdates (substitua pelo seu token) e procure pelo número "id" no texto que aparecer.
• Cole as informações no .env:
TELEGRAM_TOKEN=...
TELEGRAM_CHAT_ID=...

─────────────────────────────────────────────────────────────────

PASSO 4 — Preencher seus produtos em produtos.json
  
  Abra o arquivo produtos.json e edite cada produto:

  ┌─────────────────────────────────────────────────────────┐
  │ COMO PEGAR O LINK AFILIADO NA SHOPEE:                   │
  │  1. Entre em affiliate.shopee.com.br                    │
  │  2. Pesquise o produto                                  │
  │  3. Clique em "Gerar Link"                              │
  │  4. Copie o link encurtado (shope.ee/...)               │
  │  5. Cole em "link_afiliado"                             │
  │                                                         │
  │ COMO PEGAR O LINK AFILIADO NO MERCADO LIVRE:            │
  │  1. Entre em mercadolivre.com.br/afiliados              │
  │  2. Pesquise o produto                                  │
  │  3. Clique em "Compartilhar" → copie o link afiliado    │
  │  4. Cole em "link_afiliado"                             │
  │                                                         │
  │ COMO PEGAR A URL DA IMAGEM:                             │
  │  1. Abra a página do produto no navegador               │
  │  2. Clique com botão direito na imagem principal        │
  │  3. "Copiar endereço da imagem"                         │
  │  4. Cole em "imagens": ["URL_AQUI"]                     │
  └─────────────────────────────────────────────────────────┘

─────────────────────────────────────────────────────────────────

PASSO 5 — Configurar seu @ do TikTok
  
  Abra agents/exporter.py e edite a linha ~60:
  
    self.seu_tiktok = "SEU_USUARIO_TIKTOK_AQUI"
  
  Coloque seu usuário sem o @. Exemplo:
    self.seu_tiktok = "gilmar.achadinhos"

─────────────────────────────────────────────────────────────────

PASSO 6 — Rodar o agente
  
  No terminal, dentro da pasta affiliate-bot:
  
    python main.py
  
  Aguarde. Para 3 produtos leva ~2-3 minutos.
  Os vídeos ficam em: ./output/
